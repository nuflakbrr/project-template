# create-bpa

This is an alias package for [`create-bikinproject-app`](https://www.npmjs.com/package/create-bikinproject-app).

## Usage

```bash
npx create-bpa@latest
```

or

```bash
bun create bpa
```

For full documentation, please visit [bikinproject documentation](https://nuflakbrr.github.io/bikinproject).

## About

`create-bpa` is a shorter alias for the full `create-bikinproject-app` command. Both packages provide the same functionality - a modern CLI tool for scaffolding end-to-end type-safe TypeScript projects.

All functionality is provided by the main [`create-bikinproject-app`](https://www.npmjs.com/package/create-bikinproject-app) package.
