# BikinProject Contribution Guide

Welcome to the Contribution Guide section. We appreciate your interest in contributing to our project. This guide will help you get started with the contribution process and provide all the information you need to make meaningful contributions.

Our project is **open source**, and we welcome contributions from the community. Whether you're a developer, designer, or writer, there are many ways to contribute to our project. This guide will help you understand the contribution process and provide the necessary information to get started.

## Our Development Process

We use GitHub to synchronize code to and from our internal repository. We'll use GitHub to track issues and feature requests, as well as accept pull requests.

## Pull Requests

We actively welcome your pull requests. To contribute to this project, follow these steps:

1. **Fork Repository and Create Branch**
   - Fork this repository to your GitHub account.
   - Create a new branch from the `main` branch in your repository.

2. **Commit, Push, and Pull-Request**
   - Make your changes with clear commit descriptions.
   - Push your commits to your branch on your GitHub repository.
   - Submit a pull request from your branch to the `main` branch of this repository.

We will review submitted pull requests and respond as soon as possible. Thank you for your contribution to making BikinProject even better!

Please follow these steps carefully to ensure your contributions can be smoothly integrated into the project. If you have any questions, don't hesitate to ask.

## Issues

We use GitHub issues to track public bugs. Make sure your description is clear and has sufficient instructions to reproduce the issue. If possible, provide a minimal demo of the issue.

## Issue Management

Here are some tags we use to organize issues in this repository:

- `good first issue` - Good candidates for new contributors to the project.
- `bug` - Something isn't working and needs to be fixed.
- `help wanted` - Issues that need attention and we welcome pull requests for, but might require significant investigation or work.
- `support` - Requests for help with concepts or code snippets, but not project issues.
- `enhancement` - Feature requests.
- `discussion` - Issues where people discuss approaches and ideas about various things.
- `question` - Questions specifically for maintainers.
- `documentation` - Related to project documentation improvements.

## Adding New Templates

### Frontend

1. Clone the repository.

```bash
git clone https://github.com/nuflakbrr/frontend-template.git
```

2. Create a new branch.

```bash
git checkout -b template-name
```

3. Create new template.

4. Push to branch.

```bash
git push origin template-name
```
