---

To get started with our package, follow these simple steps:

- Git installed on your machine
- [Node.js 20.11.0](https://nodejs.org) or later
- NPM / Yarn / PNPM / Bun package manager installed on your machine
- macOS, Windows (including WSL), and Linux are supported.

## Getting Started

To get started with BikinProject, follow these simple steps:

<Stepper>
<StepperItem title="Install BikinProject">
Start by installing BikinProject on your machine.

<TerminalTabs />

</StepperItem>

<StepperItem title="Tell BikinProject Where to Create the Project">
Input a directory where you want to create your project.

```
┌   create-bikinproject-app
│
◇  Where should we create your project?
└  ./your-project # Input your project name, e.g. my-project or .
```

</StepperItem>

<StepperItem title="Choose a Starter Project">
Choose a starter project that suits your needs.

```
┌   create-bikinproject-app
│
◇  Where should we create your project?
│  ./your-project
│
◇  Pick a project type within "./your-project"
│  ● Next.js App Router (Tailwind + TypeScript)
│  ○ Next.js App Router (Tailwind + JavaScript)
│  ○ etc.
└  # Select a project type by using the arrow keys
```

</StepperItem>

<StepperItem title="Wait for BikinProject to Create the Project">
Wait for BikinProject to create the project for you.

```
┌   create-bikinproject-app
│
◇  Where should we create your project?
│  ./your-project
│
◇  Pick a project type within "./your-project"
│  Next.js App Router (Tailwind + TypeScript)
│
◇  ⏳ Creating project...
```

</StepperItem>

<StepperItem title="Choose include install dependencies">
Choose to install dependencies or not.

<Note title="Note" type="note">
  If you choose to install dependencies, BikinProject will install the necessary dependencies for
  you. Please wait for the installation to complete.
</Note>

```
┌   create-bikinproject-app
│
◇  Where should we create your project?
│  ./your-project
│
◇  Pick a project type within "./your-project"
│  Next.js App Router (Tailwind + TypeScript)
│
◇  ⏳ Creating project...
│
◇  ✅ Project created successfully!
│
◇  Do you want to install dependencies for ./your-project?
│  ● Yes / ○ No
└  # Select Yes or No by using the arrow keys
```

</StepperItem>

<StepperItem title="Choose package manager">
Choose package manager to install dependencies.

```
┌   create-bikinproject-app
│
◇  Where should we create your project?
│  ./your-project
│
◇  Pick a project type within "./your-project"
│  Next.js App Router (Tailwind + TypeScript)
│
◇  ⏳ Creating project...
│
◇  ✅ Project created successfully!
│
◇  Do you want to install dependencies for ./your-project?
│  Yes
│
◇  Pick a package manager to install dependencies for "./your-project"
│  ● NPM
│  ○ Yarn
│  ○ Bun
│  ○ PNPM
└  # Select by using the arrow keys
```

</StepperItem>

<StepperItem title="Wait for BikinProject to Install Dependencies">
Wait for BikinProject to install the dependencies for you.

```

│
◇  Where should we create your project?
```
