### Manual

#### Linux / Mac

You can follow the steps below to install the starter kit or you can simply run `bash install.sh` to install it.

<Stepper>

<StepperItem title="Clone the repositories">

```bash
npx degit nuflakbrr/fullstack-template#laravel-filament <name_of_project>
```

</StepperItem>

<StepperItem title="Install Dependencies">

```bash
composer install
```

</StepperItem>

<StepperItem title="Run Starter Kit Installation">

```bash
php artisan bikinproject:install
```

</StepperItem>

</Stepper>

#### Windows

<Stepper>

<StepperItem title="Clone the repositories">

```bash
npx degit nuflakbrr/fullstack-template#laravel-filament <name_of_project>
```

</StepperItem>

<StepperItem title="Install Dependencies">

```bash
composer install --ignore-platform-reqs
```

</StepperItem>

<StepperItem title="Run Starter Kit Installation">

```bash
php artisan bikinproject:install
```

</StepperItem>

</Stepper>

Here's the core of the `install.sh` script:

- Installs required Composer packages (`composer install`)
- Runs custom artisan script (`php artisan bikinproject:install`)
- Sets up environment (`.env` file)
- Installs Node.js dependencies
- Generates application key
- Offers to run database migrations
- Configures project name and URL
- Offers to remove installation files
- Provides instructions for starting local development server
