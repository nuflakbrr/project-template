## Reactjs Template Starter Kit

This is a [React.js](https://react.dev/) project bootstrapped with [`Vite.js`](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md).

## Technologies Used

- [React.js](https://react.dev/)
- [Tailwindcss](https://tailwindcss.com/)
- [Axios](https://axios-http.com/docs/intro/)

## Features

The features included in this project template are:

- Project Architecture.
- Authentication.
- Customize `React Hooks`.
- Some custom functions that [I](https://github.com/nuflakbrr) often use.
